# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| Latest release on GitHub | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Instead, email the maintainers or use GitHub **Private vulnerability reporting** (if enabled on the repository) with:

- Description of the issue and impact
- Steps to reproduce
- Affected versions
- Suggested fix (if any)

We aim to acknowledge reports within 7 days.

## Scope notes

AntiSmurf interacts with the local StarCraft II client (window automation, clipboard, replay files). It does not modify game memory or inject into the SC2 process. Users should only download releases from the official GitHub Releases page or sources they trust.
